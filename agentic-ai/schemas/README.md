# Schemas

Shared data contracts passed between agents:

- `plan` — Intake & Planning Agent output (service ID, steps, assigned agents)
- `eligibility-result` — Eligibility & Document Analysis Agent output
  (eligible?, missing-document list)
- `draft-application` — Action/Tool Agent output (pre-filled application,
  fee, proposed appointment slot)
- `validation-result` — Validation & Safety Agent output (validated
  application or rejection reasons)
